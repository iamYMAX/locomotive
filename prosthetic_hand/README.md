# Прототип роботизированной кисти-протеза

Этот проект представляет собой прототип для управления всей кистью (5 пальцев) с помощью одного мышечного сигнала (ЭМГ).

## Описание

Код, написанный для платформы ESP32, считывает аналоговые данные с одного ЭМГ-датчика и синхронно управляет пятью сервоприводами. Это позволяет реализовать базовые жесты "сжатие кулака" и "открытая ладонь". Чем сильнее сокращается мышца, тем сильнее сгибаются все пальцы.

Это второй этап в создании полноценного протеза, развивающий первоначальный прототип.

## Оборудование

Для сборки вам понадобятся:
1.  **Микроконтроллер:** ESP32 (любая модель).
2.  **ЭМГ-датчик:** 1 шт. (например, MyoWare Muscle Sensor v2 или аналог).
3.  **Сервоприводы:** 5 шт. (например, SG90 или MG996R).
4.  **Источник питания:** Способный обеспечить питанием ESP32 и все 5 сервоприводов.
5.  **Соединительные провода.**

## Программное обеспечение

*   **Среда разработки:** Arduino IDE
*   **Пакет для платы:** `esp32` от Espressif Systems (устанавливается через Менеджер плат в Arduino IDE).
*   **Библиотека:** `ESP32Servo`.

## Установка и использование

### 1. Подключение

*   **Сервоприводы:**
    *   Большой палец: `Сигнальный провод` -> Пин `13` (SERVO_THUMB_PIN)
    *   Указательный палец: `Сигнальный провод` -> Пин `12` (SERVO_INDEX_PIN)
    *   Средний палец: `Сигнальный провод` -> Пин `14` (SERVO_MIDDLE_PIN)
    *   Безымянный палец: `Сигнальный провод` -> Пин `27` (SERVO_RING_PIN)
    *   Мизинец: `Сигнальный провод` -> Пин `26` (SERVO_PINKY_PIN)
    *   Все сервоприводы: `VCC` -> `5V`, `GND` -> `GND`
*   **ЭМГ-датчик:**
    *   `Сигнальный выход` -> Пин `34` на ESP32 (или другой, указанный в `config.h`)
    *   `VCC` -> `3.3V` или `5V` (в зависимости от датчика)
    *   `GND` -> `GND`

**Внимание:** Убедитесь, что ваш источник питания способен обеспечить достаточный ток для сервопривода, особенно в момент старта.

### 2. Настройка и калибровка

1.  Откройте файл `prosthetic_hand.ino` в Arduino IDE.
2.  Откройте файл `config.h`. В нем находятся основные настройки.
3.  **Откалибруйте датчик:** Это самый важный шаг.
    *   Загрузите скетч на ESP32.
    *   Откройте **Монитор последовательного порта** (скорость 115200).
    *   Наблюдайте за значениями `Smoothed` в консоли.
    *   Полностью расслабьте мышцу и запишите среднее значение. Впишите его в `EMG_MIN_THRESHOLD` в файле `config.h`.
    *   Максимально напрягите мышцу и запишите пиковое значение. Впишите его в `EMG_MAX_THRESHOLD`.
4.  Сохраните изменения в `config.h`.

### 3. Загрузка и запуск

1.  Выберите вашу плату ESP32 и правильный COM-порт в меню "Инструменты".
2.  Нажмите кнопку "Загрузить".
3.  После загрузки сервопривод должен реагировать на напряжение вашей мышцы.

---
Этот прототип является основой. Следующие шаги будут включать добавление большего количества пальцев, распознавание жестов и интеграцию с камерой.
