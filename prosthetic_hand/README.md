# Прототип роботизированной кисти-протеза

Этот проект представляет собой прототип для управления всей кистью (5 пальцев) с помощью одного мышечного сигнала (ЭМГ).

## Описание

Код, написанный для платформы ESP32, считывает аналоговые данные с одного ЭМГ-датчика и, в зависимости от силы сигнала, выполняет один из трех предустановленных жестов:
- **Открытая ладонь:** При расслабленной мышце.
- **Щипок:** При слабом напряжении мышцы (сгибаются большой и указательный пальцы).
- **Кулак:** При сильном напряжении мышцы (сгибаются все пальцы).

Эта версия реализует систему управления жестами на основе пороговых значений, что является следующим шагом в развитии проекта.

## Оборудование

Для сборки вам понадобятся:
1.  **Микроконтроллер:** ESP32 (любая модель).
2.  **ЭМГ-датчик:** 1 шт. (например, MyoWare Muscle Sensor v2 или аналог).
3.  **Сервоприводы:** 5 шт. (например, SG90 или MG996R).
4.  **Источник питания:** Способный обеспечить питанием ESP32 и все 5 сервоприводов.
5.  **Соединительные провода.**

## Программное обеспечение

*   **Среда разработки:** Arduino IDE
*   **Пакет для платы:** `esp32` от Espressif Systems (устанавливается через Менеджер плат в Arduino IDE).
*   **Библиотека:** `ESP32Servo`.

## Установка и использование

### 1. Подключение

*   **Сервоприводы:**
    *   Большой палец: `Сигнальный провод` -> Пин `13` (SERVO_THUMB_PIN)
    *   Указательный палец: `Сигнальный провод` -> Пин `12` (SERVO_INDEX_PIN)
    *   Средний палец: `Сигнальный провод` -> Пин `14` (SERVO_MIDDLE_PIN)
    *   Безымянный палец: `Сигнальный провод` -> Пин `27` (SERVO_RING_PIN)
    *   Мизинец: `Сигнальный провод` -> Пин `26` (SERVO_PINKY_PIN)
    *   Все сервоприводы: `VCC` -> `5V`, `GND` -> `GND`
*   **ЭМГ-датчик:**
    *   `Сигнальный выход` -> Пин `34` на ESP32 (или другой, указанный в `config.h`)
    *   `VCC` -> `3.3V` или `5V` (в зависимости от датчика)
    *   `GND` -> `GND`

**Внимание:** Убедитесь, что ваш источник питания способен обеспечить достаточный ток для сервопривода, особенно в момент старта.

### 2. Настройка и калибровка

1.  Откройте проект в Arduino IDE и перейдите в файл `config.h`.
2.  **Откалибруйте пороги срабатывания:** Это самый важный шаг для корректной работы жестов.
    *   Загрузите скетч на ESP32.
    *   Откройте **Монитор последовательного порта** (скорость 115200). В нем будут отображаться текущее сглаженное значение (`Smoothed`) и активный жест.
    *   **Для `EMG_THRESHOLD_PINCH`:** Слегка напрягите мышцу, чтобы выполнить жест "щипок", и посмотрите на значения `Smoothed`. Выберите пороговое значение, которое будет надежно отделять состояние покоя от слабого напряжения. Запишите его.
    *   **Для `EMG_THRESHOLD_FIST`:** Сильно напрягите мышцу для жеста "кулак". Выберите пороговое значение, которое будет отделять слабое напряжение от сильного.
    *   Внесите найденные значения в `EMG_THRESHOLD_PINCH` и `EMG_THRESHOLD_FIST` в файле `config.h`.
3.  **(Опционально) Настройте углы сервоприводов:** Если стандартные углы (`SERVO_ANGLE_OPEN`, `SERVO_ANGLE_CLOSED` и т.д.) не подходят для вашей механики, вы можете изменить их в `config.h`.
4.  Сохраните изменения и снова загрузите прошивку.

### 3. Загрузка и запуск

1.  Выберите вашу плату ESP32 и правильный COM-порт в меню "Инструменты".
2.  Нажмите кнопку "Загрузить".
3.  После загрузки сервопривод должен реагировать на напряжение вашей мышцы.
