# Система управления игрушечным паровозом Piko на Arduino

## Инструкция по загрузке, подключению и настройке

### 1. Прошивка микроконтроллеров

#### Ведущий контроллер (Депо):
1.  Откройте `master.ino` в Arduino IDE.
2.  Выберите плату "Arduino Nano".
3.  Выберите правильный порт.
4.  Загрузите прошивку.

#### Ведомые контроллеры (Столы):
1.  Откройте `slave.ino` в Arduino IDE.
2.  **Важно:** Измените значение `#define SLAVE_ID 1` на уникальный номер для каждого стола (от 1 до 5).
3.  Выберите плату "Arduino Nano".
4.  Выберите правильный порт.
5.  Загрузите прошивку.
6.  Повторите для каждого ведомого контроллера.

### 2. Подключение

Следуйте схеме подключения, указанной в техническом задании. Убедитесь, что все соединения выполнены правильно, особенно питание и линия данных RS-485.

### 3. Настройка

После прошивки и подключения всех компонентов, система готова к работе. Ведущий контроллер автоматически инициализирует ведомые и перейдет в режим ожидания команды.

### 4. Использование

Используйте матричную клавиатуру для выбора стола, на который должен отправиться паровоз. Ведущий контроллер отправит команду на соответствующий ведомый контроллер для переключения стрелки, а затем запустит движение паровоза. После прибытия на стол, паровоз будет ждать 45 секунд, а затем автоматически вернется в депо.
