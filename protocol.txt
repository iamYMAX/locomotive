Формат сообщения: [SRC_ID]|[DST_ID]|[CMD]|[DATA]\n

- SRC_ID: ID отправителя (0 для ведущего, 1-5 для ведомых).
- DST_ID: ID получателя (0 для ведущего, 1-5 для ведомых).
- CMD: Команда.
- DATA: Данные (опционально).
- \n: Маркер конца сообщения.

Примеры команд:

Ведущий -> Ведомый:
- 0|{ID}|SWITCH|1 - Переключить стрелку в положение 1.
- 0|{ID}|LED_ON|GREEN - Включить зеленый светодиод.
- 0|{ID}|LED_OFF|RED - Выключить красный светодиод.
- 0|{ID}|PING| - Проверить связь.

Ведомый -> Ведущий:
- {ID}|0|CONFIRM|SWITCH - Подтверждение переключения стрелки.
- {ID}|0|SENSOR|U1 - Сработал датчик Холла U1.
- {ID}|0|PONG| - Ответ на PING.
- {ID}|0|ERROR|Invalid command - Сообщение об ошибке.
